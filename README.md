# Elementor Extra Motion

Elementor Extra Motion is a WordPress plugin that extends Elementor with additional motion and animation effects.

## Description

This plugin adds extra motion effects for layouts, widgets, and entrance animations in Elementor-based sites.

## Installation

1. Copy the `elementor-extra-motion` plugin folder into `wp-content/plugins/`.
2. Activate the plugin in the WordPress admin under Plugins.
3. Ensure Elementor is installed and active.

## Features

- Layout motion effects
- Widget motion enhancements
- Entrance animations
- Plugin settings and activation handling

## Files

- `elementor-extra-motion.php` - Plugin bootstrap and initialization.
- `admin/` - Admin settings and activation hooks.
- `assets/` - CSS and JavaScript for motion effects.
- `includes/` - Core plugin logic for animations and features.

## Usage

After activation, configure the plugin in the WordPress admin if there are settings available. The plugin automatically loads extra motion effects based on the configured options.
